# 14 · Flujos de trabajo: GitHub Flow, Git Flow y trunk-based

## Resumen

- GitHub Flow: simple (empieza aquí)
- Git Flow: estructurado, con develop
- Trunk-based: ágil, despliegue continuo

### ¿Cuál elegir?

| ✅ Empieza con GitHub Flow | 🏢 Los otros, según el caso |
|---|---|
| Proyectos personales | Git Flow: versiones planificadas |
| Equipos pequeños | Trunk-based: despliegue continuo |
| Simple y claro |  |

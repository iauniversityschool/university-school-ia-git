# Git desde cero hasta avanzado — University School IA

Material del curso **Git desde cero hasta avanzado** del canal [University School IA](https://www.youtube.com/@UniversitySchoolIA), explicado por el **Profesor Mimir IA**.

Aprende Git desde tu primer `commit` hasta flujos profesionales (rebase, tags, workflows y rescate de commits). No necesitas conocimientos previos.

## Cómo usar este repositorio

Cada carpeta es una lección. Dentro encontrarás un `README.md` con el resumen, los comandos y el mini-reto con su solución. A lo largo del curso construimos juntos un proyecto de ejemplo llamado `mi-web`.

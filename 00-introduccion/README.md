# 00 · Introducción: ¿Qué es Git y por qué lo necesitas?

## Resumen

- **Git** es un sistema de **control de versiones**: una "máquina del tiempo" para tu proyecto. Guarda fotos de tus archivos llamadas **commits**.
- **Git ≠ GitHub.** Git es la herramienta que corre en tu computadora (funciona sin internet). **GitHub** es un sitio web donde subes tus proyectos a la nube para respaldarlos y compartirlos.
- Se usa para: historial completo, probar ideas en ramas sin romper nada, trabajar en equipo y tener respaldo en la nube.

## El mapa del curso

1. **Fundamentos** — instalar Git y tu primer commit.
2. **Ramas y fusiones.**
3. **GitHub y trabajo en equipo.**
4. **Avanzado** — rebase, tags, rescate de commits.
5. **Profesional + proyecto final.**

A lo largo del curso construimos el proyecto de ejemplo `mi-web`.
